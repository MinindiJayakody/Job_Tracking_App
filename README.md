# Job Tracker

Job Tracker is a Flutter app for organizing job opportunities in one place. It helps you keep track of roles you want to apply for, jobs you have saved, and applications you have already submitted.

## Features

- Add new job opportunities
- Edit existing jobs
- Delete jobs you no longer need
- Move jobs between statuses:
  - To apply
  - Saved
  - Applied
- Search jobs by title, company, location, salary, or notes
- View job counts by status
- Persist data locally using `shared_preferences`
- Clean Material 3 UI with a responsive layout

## Tech Stack

- Flutter
- Dart
- shared_preferences

## Getting Started

### Prerequisites

- Flutter SDK installed
- Android Studio, VS Code, or another Flutter-compatible editor
- A connected device, emulator, or browser for running the app
